## Vision and scope

North star remains learn, earn, connect and create real-world opportunities, with human approval and contextual Trust. Reuse Tonguee as the first verified vertical. English/light is the initial presentation priority; preserve existing locale/theme behavior. Mascots help users create; they do not certify hosts or authorize actions.

The recommended first controlled pilot proves one complete host and learner journey in an approved category and launch area. A free pilot can validate operations; calling paid earning features production-ready requires the separate money package. The wider P1–P5 opportunity engine remains the governed core. Global category launch, Seasons, AR, complex venue intelligence and subscriptions are later individually approved packages. Existing Calgary references are inherited pilot scope; this audit does not invent or change geography.
