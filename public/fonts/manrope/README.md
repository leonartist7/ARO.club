# Manrope webfonts

These unmodified WOFF2 subsets are the Manrope v20 files served by Google Fonts for the existing 400, 500, 600 and 700 weight request. They are stored locally so the app renders the same body typeface without a browser request to Google Fonts. The subsets and Unicode ranges in `src/index.css` follow the [Google Fonts stylesheet](https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700&display=swap); the files come from `https://fonts.gstatic.com/s/manrope/v20/`. The included `OFL.txt` is from [Google Fonts' Manrope source](https://github.com/google/fonts/tree/main/ofl/manrope).
